Panduan Monev Lapangan

1. Buka Kamera HP: Klik tombol "Buka Kamera HP". Gunakan tombol "Stop" untuk mematikan kamera.

2. Tandai Titik A (Awal): Tekan tombol "1. SET TITIK AWAL (A)". Marker hijau berkedip akan muncul di peta dan foto awal akan diambil.

3. Berjalan ke Ujung Segmen: Berjalanlah menyusuri jalan. Garis biru akan otomatis ditarik mengikuti pergerakan GPS.

4. Tandai Titik B (Akhir): Tekan tombol "2. SET TITIK AKHIR (B)". Marker merah akan dikunci dan total jarak otomatis dihitung.

5. Simpan & Kirim: Pilih jenis kerusakan, isi catatan. Klik "Simpan & Kirim ke Google Sheet" untuk upload data + foto ke server.

6. Lihat Riwayat: Klik tab "Server" lalu tombol "Muat Server" untuk melihat data yang sudah tersimpan di Google Sheet.
