Panduan Monev Lapangan

1. Buka Kamera HP: Klik tombol "Buka Kamera HP". Gunakan tombol "Stop" untuk mematikan kamera.

2. Tandai Titik A (Awal): Tekan tombol "1. SET TITIK AWAL (A)". Akan muncul kalibrasi GPS 5 detik — diam di tempat sampai selesai.

3. Berjalan ke Ujung Segmen: Berjalanlah menyusuri jalan. Garis biru akan otomatis ditarik mengikuti pergerakan GPS Anda.

4. Tandai Titik B (Akhir): Tekan tombol "2. SET TITIK AKHIR (B)". Kalibrasi 5 detik lagi, lalu jarak otomatis dihitung dari jejak GPS (polyline).

5. Auto-Mode: Jika beda jarak polyline vs lurus > 5%, sistem otomatis pakai polyline (lebih akurat untuk jalan berbelok).

6. Segmen Baru: Setelah simpan, klik "Segmen Baru" untuk mengukur segmen berikutnya. Setiap segmen diberi warna & nomor di peta.

7. Simpan & Kirim: Pilih jenis pemeriksaan, isi catatan. Klik "Simpan & Kirim ke Google Sheet" untuk upload.
